An open learning path: for anyone learning GIS on their own, at their own pace. See Learning paths for how paths work.

Most GIS courses start with the software: this button buffers, that one clips. This path starts with the world. You learn to say what you are looking at and what question you are asking of it, to find the data that can answer the question, and to choose the operation that turns the data into an answer. The software comes last, as the Recipe that carries the operation out. Once you work this way, changing tools (QGIS, ArcGIS Pro, Python) changes only the last step.

You need: a computer that can run QGIS (free), and curiosity about a place you know. No earlier GIS experience.

Afterwards you can: turn a question about a place into a documented GIS workflow: what you observe, which data stand for it, which operations answer the question, and why you chose them.

The path

Each stage starts with the question it answers. Read the notes in the “Read” column first, then work through the Tasks and Examples.

5. Specialising

What do the questions of my field look like?

Choose a Domain hub close to your interests: landscape ecology, biodiversity, soil, climate, housing, hydrology, urban design, transport, energy, land use planning or ethnography. Each hub lists the questions the field asks, the data it often uses, and worked Examples. Work through one Example from start to end, and write down your choices as a Design Rationale.
