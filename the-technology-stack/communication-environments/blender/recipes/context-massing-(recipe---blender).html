Context massing (Recipe — Blender)

Context massing (Recipe — Blender)

Properties1
tags—

Nov 26, 20266 min read

Tool-bound implementation of the Context massing (Task) Schema. Input from Building heights from DHM (Recipe - QGIS). Used in Urban Design Visualisation (Example) (step 4). Budget: one working session.

Before you start

Install BlenderGIS

  1. On github.com/domlysz/BlenderGIS click Code → Download ZIP. Do not unzip it (on Mac, Safari may unzip automatically — re-zip the folder or turn off Open safe files after downloading).
  2. In Blender: Edit → Preferences → Add-ons, click the small arrow ⌄ top right → Install from Disk… and select the zip.
  3. Search for GIS in the add-on list and tick the checkbox.
  4. Check: a GIS menu now appears in the header of the 3D viewport (Object Mode).

Use the same Blender version as everyone else in your group.

Add the Danish coordinate system. BlenderGIS only knows WGS84 and Web Mercator out of the box.

  1. Edit → Preferences → Add-ons → BlenderGIS, expand it, find Spatial Reference Systems and click +.
  2. Definition: EPSG:25832 (include “EPSG:”). Description: ETRS89 / UTM 32N.
  3. Tick Save to addon preferences if shown, then Save Preferences (☰ bottom left).

1. Scene setup

  1. New file, delete the default cube, save as 04_blender/context.blend.
  2. Scene Properties → Units: Metric, Unit Scale 1.0 (1 unit = 1 m).
  3. Press N in the 3D viewport → GIS tab → Geoscene: set the CRS to ETRS89 / UTM 32N.

2. Terrain (optional but recommended)

GIS → Import → Georeferenced raster, select terrain.tif, mode DEM as mesh (or displacement). BlenderGIS moves the scene origin close to your data automatically, so the model stays precise.

3. Import and extrude the buildings

Import the two building files one at a time with GIS → Import → Shapefile:

The LOD2 buildings now stand at their eave height, ready for a roof. Keep the attribute table of context_lod2 open in QGIS: roof_rise tells you how far to raise each ridge.

4. One material for all context

  1. Select all buildings and create one material context_white: Base Color very light grey (about 0.85), Roughness 0.8, no texture.
  2. With all selected, and the one with the material active: Ctrl+L → Link Materials.

That is the whole context material. Do not add brick, glass or facade textures.

5. LOD2 roofs — only where they matter

Roofs are made in Edit Mode by adding a ridge and raising it by roof_rise. Check the roof direction and type against the orthophoto, oblique photos (skråfoto) or your own site photos. Within about half a metre is accurate enough. Note the source you used for each building — it belongs in the Design Rationale.

Gable roof (rectangular building)

  1. Tab, press 2, select the two short top edges (Shift-click the second).
  2. Right-click → Subdivide (1 cut) — adds a midpoint on each edge.
  3. Press 1, select the two new midpoints, press J (Connect Vertex Path) — this is the ridge.
  4. G Z, type the building’s roof_rise, Enter.

This keeps the walls clean; a loop cut would add lines down the facades.

  • Hipped roof: make a gable, then with the ridge still selected press S, the ridge axis (X or Y) and e.g. 0.5, Enter.
  • Pyramid roof (towers, square buildings): select the top face, right-click → Poke Faces, then G Z and roof_rise.
  • Mansard roof (common in Danish town centres): select the top face, I (Inset) about 1–1.5 m, then G Z about 2.5 m for the steep lower part. Add a low gable or hip on the inner face if needed.
  • Flat roof with parapet: select the top face, I 0.3 m, then E and -0.5 so the roof sits inside a 0.5 m edge.
  • L-shaped and complex footprints: split the top face into rectangles first (select two vertices on opposite edges, J), make a gable on each wing, and join ridge ends with M → At Center.
  • Faster option: the free Building Tools add-on (N sidebar → Building Tools → Roof) makes flat, gable and hipped roofs from a selected top face with adjustable pitch. Best on simple footprints.

Finish each building: Mesh → Clean Up → Merge by Distance (removes duplicate vertices) and Shift+N (Recalculate Normals, all faces point outwards — needed for Twinmotion and the export back to QGIS).

6. The proposal goes in its own collection

Model the proposal (terrain changes, planting beds, water, furniture, pavilions) in a collection called design. This is where modelling time, materials and detail belong. Trees and people are added later in Twinmotion.

Before exporting: Object → Apply → All Transforms on everything.

7. Export for Twinmotion

Export two files, so the design can be updated without touching the context:

FileContainsFBX settings
03_exchange/context.fbxCollections context_LOD1, context_LOD2, terrainSelected objects, Scale 1.0, Apply Unit and Apply Transform on
03_exchange/design.fbxCollection designSame settings; materials named clearly (paving_granite, water, bench_wood)

Optional — back to QGIS as 3D buildings

The edited buildings, including LOD2 roofs, can go back to QGIS at their real coordinates.

  1. Select the buildings, then Object → Apply → All Transforms.
  2. GIS → Export → Shapefile: geometry type PolygonZ, mode Objects to features (one feature per building). BlenderGIS adds the Geoscene offset back and writes the .prj file.
  3. In QGIS, add the Shapefile, open View → 3D Map Views → New 3D Map View, and in the layer’s Properties → 3D View set: Single symbol, altitude clamping Absolute, extrusion 0, culling No culling.
  4. Save as GeoPackage: Export → Save Features As…, geometry type MultiPolygon, tick Include z-dimension.

Don’t use QGIS’s OBJ export of a 3D scene as a base for Blender: it loses the coordinates and building IDs.

Troubleshooting

ProblemCauseFix
No GIS menu in BlenderAdd-on installed but not enabled, or you are in Edit ModeTick BlenderGIS in Preferences; switch to Object Mode
Buildings end up near 0,0 or far from the terrainGeoscene CRS not set, or a different CRS on importSet the Geoscene to ETRS89 / UTM 32N before importing anything
All buildings have the same heightWrong field in Extrusion from field, or the field is textCheck that height is a decimal field in QGIS
Buildings float or sinkNo ground elevation usedUse Elevation from field ground, or place on the terrain
